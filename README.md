# Beirando-App
Beirando is a mobile app designed to help students from any colleges, specially from University of Brasília (UnB) to keep track of the classes they have missed.


## Technologies

### Backend
- Node.js
- Sequelize
- MySQL

### Mobile (Frontend)
- React Native
- Expo
